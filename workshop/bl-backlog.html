What is a backlog?

// the backlog

A backlog in web dev is a prioritized list of all the work that needs to be done for a website.

Think of it as a dynamic "to-do list" that CROs can follow and keep orderly documentation on progress. This is a professional approach rather than the ad hoc testing you see happening at most ecommerce brands.

In order to make it an on-going program, you simply need to add in a loop. That way you not only have your finger on the pulse of the progress, but a clear idea of the upcoming changes you can expect — this is especially important if your boss is a psycho.
